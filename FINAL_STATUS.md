# Final Build Status

This package integrates two chat modes into the v0.9 project: a no-API Python rule-based chat and optional local Ollama chat. Network propagation UI has been aligned with the current `propagate_payment_shock` function signature and DataFrame result.

Verification performed for this build: Python compilation, automated tests, and source-level checks. Live Ollama interaction was not tested because Ollama is not installed in the build environment. Install Ollama and download the model on the user's Windows laptop to validate local inference.

This is a competition prototype, not production financial software.
